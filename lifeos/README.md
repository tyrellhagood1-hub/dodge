# LifeOS

Minimal Expo Router (tabs) starter for a personal “OS” dashboard.

## Structure

- `app/_layout.tsx`: root stack
- `app/(tabs)/_layout.tsx`: bottom tab navigation
- `app/(tabs)/*.tsx`: tab screens
- `components/*`: shared UI components
- `services/*`: placeholder data sources
- `constants/colors.ts`: theme tokens

## Run

```bash
cd lifeos
npm install
npm start
```
